# 인천학원연합회 OS 공식 다운로드

이 저장소는 **인천학원연합회 OS의 공개 설치파일 배포 전용 저장소**입니다.

- 개발 소스코드는 이 저장소에 공개하지 않습니다.
- Windows/macOS 설치파일과 체크섬, 릴리스 노트만 게시합니다.
- 공식 설치센터: https://incheon-academy-union-os-web.vercel.app/download
- 제품 ID: `kr.or.incheonacademy.unionos`

## 배포 채널

- Windows 10/11 x64
- Windows 7/8/8.1 Legacy x64
- macOS 13+ Universal
- macOS Mojave 10.14.6 Intel x64

> 현재 데스크톱 설치파일은 코드서명/Apple notarization 전 빌드입니다. 운영체제에서 보안 경고가 표시될 수 있습니다.
